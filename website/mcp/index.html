Write design documents with AI through a local MCP server

design-dawn-mcp is a small program that comes with Design Dawn. It speaks the Model Context Protocol (MCP), so an AI tool such as Claude, Codex, GitHub Copilot, Cursor or any other MCP client can read your design documents and, when you allow it, edit them.

Set-up, once per AI tool

In the app, open File → AI Integration (MCP). It shows the command to register, with a Copy button, and the same thing in the common JSON form:

{
  "mcpServers": {
    "design-dawn": { "command": "C:\\path\\to\\design-dawn-mcp.exe" }
  }
}

Register it the way your AI tool adds MCP servers. For Claude Code, for example:

claude mcp add design-dawn -- <command>

No project is named in the registration; the server takes no arguments. The server talks over standard input and output only. It opens no network port, and it works whether or not the app is running.

You choose which projects AI can see

An AI tool can use only the projects in the AI Integration screen’s list. Add them there (Add the Open Project, or Add a Folder…), or let the AI add one with addProject — you approve that call in your AI tool. By default it works on the project open in the app, if that project has been added. It can list the added projects and pick one, so a request like “summarize the order-service project” needs no new registration.

Read-only until you allow editing

A project in the list is read-only for AI until changes are allowed: tick Allow editing by AI next to it, or let the AI call setWriteAccess. Like every other tool call that is not read-only, addProject, setWriteAccess and each change are approved by you in the AI tool (for example Claude Code’s permission prompt), so the decisions stay where you are working with the AI.

The list is kept in the app’s settings folder as ai-access.json (never inside a project) and is shared by the app and the MCP server: what the AI changes there shows in the AI Integration screen at once, and every change by AI is listed in AI Change History.

What an AI tool can do

ProjectsTools
Any project in the listlistProjects, selectProject, addProject, setWriteAccess, getProject, getDocument, getSheet, getBlock, searchProject, exportMarkdown, listTemplates
Projects allowed to be editedcreateDocument, createSheet, createBlock, createFromTemplate, updateDocument, updateSheet, updateBlock, moveBlock, updateBlockDisplay, updateBlockCaption, deleteBlock, importImage
  • createBlock makes Markdown or Mermaid blocks; importImage adds an image file of this computer as an image block. updateBlockDisplay sets the display size of a block (or fits it to the block), updateBlockCaption the caption of a Mermaid or image block.
  • To change a block’s text, the AI reads it with getBlock and sends back its contentHash. If the text changed in the meantime, the call returns conflict instead of overwriting your edit.
  • If the app has the project open, changes made by the AI appear at once.

What it cannot do

The server cannot delete documents, sheets or projects, run commands, use Git, or open network connections. Apart from importImage (an image you name, copied into the project), it reads and writes nothing outside the projects in the list.
