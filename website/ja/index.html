自由配置キャンバスで設計書を書く

Design Dawn は、ソフトウェアの設計書（設計ドキュメント）を書くための無料・オープンソースのデスクトップアプリです。 Markdown・Mermaid の図・画像をシート上の好きな位置に置けて、 すべてが普通のテキストファイルとして保存されるので、人が読め、Git で差分を見られ、AI ツールも安全に編集できます。

GitHub で入手 Windows 版をダウンロード ビルド方法

設計書のための Markdown・Mermaid エディタ

ドキュメントは複数のシートからなり、各シートにブロックを自由に配置できます。長い1本のページではなく、文章・図・画面写真を並べて書けます。

自由配置キャンバス

パン・ズーム・選択・移動・リサイズ・整列・重なり順。すべての編集を Undo / Redo できます。

Project ツリー

Document をフォルダで整理し、複数を同時に開けます。行のドラッグで並べ替え・移動できます。

Markdown ブロック

キャンバス上では表示結果、編集中はソースとプレビューの分割表示。

Mermaid の図

Mermaid のあらゆる図をローカルで描画・サニタイズ。ネットワークもスクリプトも使いません。

Mermaid の GUI 編集

フローチャート・シーケンス図・ガントチャート・円グラフを、構文を書かずに一覧とプロパティ欄で編集。正本は Mermaid のソースのままです。

Git 連携

状態・ステージ・コミット・履歴・左右比較の差分・フェッチ / プル / プッシュをアプリ内で。

外部変更の検知

他のエディタ・Git・AI ツールによる変更を検知。読み直す・維持する・比較するを選べます。

画像とキャプション

PNG・JPEG・WebP・SVG・GIF をドラッグ & ドロップで。図には1行のキャプションを付けられます。

ライト / ダーク、日本語 / 英語

2つのテーマと2つの表示言語に対応しています。

画面

構文を覚えなくても編集できる図と、読みやすいままの差分。（画面は英語表示です）

Docs as Code：テキストで保存、読める差分

配置は小さな JSON ファイルに、内容は .md と .mmd ファイルに保存されます。 設計の変更をプルリクエストでレビューでき、人や AI が1つのブロックだけを他に触れずに変更できます。 すべての JSON に schemaVersion があり、ID は変わらない UUID です。

独自のデータベースは使わず、ロックインもありません。Design Dawn をやめても、ドキュメントは Markdown と Mermaid のまま残ります。

my-project/
├── project.json
├── system-design.dawn
└── documents/
    └── system-design/
        ├── document.json
        ├── assets/
        └── sheets/
            └── overview/
                ├── sheet.json
                └── blocks/
                    ├── markdown-1.md
                    └── mermaid-1.mmd

AI に設計書を読み書きさせる（MCP）

design-dawn-mcp はローカルの MCP サーバー（標準入出力のみ、ネットワークポートなし）で、 Claude・Codex・GitHub Copilot・Cursor などの MCP クライアントが、あなたが許可した Project を読み書きできます。

どの Project も、編集を許可するまでは AI からは読み取り専用です。AI は書き込みを依頼できますが、決めるのはアプリでのあなたの回答だけです。 編集は内容のハッシュで確認されるため、同時の変更は黙って上書きされず衝突として返ります。

claude mcp add design-dawn -- /path/to/design-dawn-mcp

よくある質問

無料ですか？

はい。MIT ライセンスのオープンソースです。

対応 OS は？

Windows 11 です（ダウンロードしてすぐ使えます）。Linux ではソースからビルドして使えます。Tauri 2（Rust と TypeScript）で作られています。

Markdown エディタやホワイトボードツールとの違いは？

両方の良さを組み合わせています。ホワイトボードのように Markdown と Mermaid のブロックを自由に置けて、しかも保存はすべて Git やコードレビューで扱えるテキストファイルです。

インターネット接続は必要ですか？

不要です。図はローカルで描画され、MCP サーバーもネットワークに接続しません。
