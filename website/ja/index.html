設計書アプリ · Markdown · Mermaid · Git · MCP

自由に並べて、AI と書く。

Design Dawn は、設計書（設計ドキュメント）を書くための無料・オープンソースのデスクトップアプリです。 メモ（Markdown）・Mermaid の図・画像をシートの好きな場所に置き、 Claude・Codex・GitHub Copilot・Cursor などの AI ツールには、許可した範囲だけを手伝ってもらえます。 すべて普通のファイルとして手元に残ります。

GitHub ダウンロード ビルド方法

設計書のための Markdown・Mermaid エディタ

ドキュメントは複数のシートからなり、各シートにブロックを自由に配置できます。長い1本のページではなく、文章・図・画面写真を並べて書けます。

自由配置キャンバス

パン・ズーム・選択・移動・リサイズ・整列・重なり順。編集は Undo / Redo できます。

Project ツリー

Document をフォルダで整理し、複数を同時に開けます。行のドラッグで並べ替え・移動できます。

Markdown ブロック

キャンバス上では表示結果、編集中はソースとプレビューの分割表示。

Mermaid の図

Mermaid 12 で描ける図をローカルで描画・サニタイズ。ネットワークもスクリプトも使いません。

Mermaid の GUI 編集

フローチャート・シーケンス図・クラス図・状態遷移図・ER 図・ガントチャート・円グラフを、構文を書かずに一覧とプロパティ欄で編集。正本は Mermaid のソースのままです。

Git 連携

状態・ステージ・コミット・履歴・左右比較の差分と、シートの見た目での比較。マージの競合もアプリ内で解決（画像は両方を見て選ぶ）。フェッチ / プル / プッシュも。

外部変更の検知

他のエディタ・Git・AI ツールによる変更を検知。読み直す・維持する・比較するを選べます。

画像とキャプション

PNG・JPEG・WebP・SVG・GIF をドラッグ & ドロップで。図には1行のキャプションを付けられます。

表示サイズと自動調整

ブロックの中の文字や図を拡大・縮小、またはブロックに合わせて自動調整。画像は元の大きさに戻せます。

テンプレート・印刷・書き出し

テンプレート（自分で作ったものも）から設計書を作成。印刷し、PDF・HTML・Markdown に書き出せます。

検索と表計算の取り込み

Project 全体を検索。表計算ファイルの表を Markdown の表として取り込めます。

ライト / ダーク、日本語 / 英語

2つのテーマと2つの表示言語に対応しています。

構文を覚えなくても編集できる図と、読みやすいままの差分。（画面は英語表示です）

普通のファイルで保存。ソースコードと同じように変更を管理

メモは .md、図は .mmd のファイルとして、配置は小さな JSON ファイルとして保存されます。 どのテキストエディタでも開け、Git を使えば設計のどこが変わったかを行単位で確認し、ソースコードと同じようにプルリクエストでレビューできます（「Docs as Code」と呼ばれる進め方です）。 人や AI が1つのブロックだけを、他に触れずに変更することもできます。 ドキュメント・シート・ブロックにはずっと変わらない ID が付いているので、名前を変えても周りのファイルが壊れることはありません。

独自のデータベースは使わず、ロックインもありません。Design Dawn をやめても、ドキュメントは Markdown と Mermaid のまま残ります。

設計書を Git で管理する方法 →

デモ Project: Design Dawn 自身の設計書（英語）。MCP サーバー経由で Design Dawn で書いたもので、.md / .mmd のファイルを GitHub 上でそのまま読めます。

my-project/
├── project.json
├── system-design.dawn
└── documents/
    └── system-design/
        ├── document.json
        ├── assets/
        └── sheets/
            └── overview/
                ├── sheet.json
                └── blocks/
                    ├── markdown-1.md
                    └── mermaid-1.mmd

AI に設計書を読み書きさせる（MCP）

design-dawn-mcp はローカルの MCP サーバー（標準入出力のみ、ネットワークポートなし）で、 Claude・Codex・GitHub Copilot・Cursor などの MCP クライアントが、あなたが許可した Project を読み書きできます。

どの Project も、編集を許可するまでは AI からは読み取り専用です。編集の許可は、アプリで付けるか、AI ツールで AI の依頼を承認して付けます（Claude Code の許可の確認など）。 Block の本文は AI が読んだときの内容と照らして書き換えるので、その間の変更は黙って上書きされず衝突として返ります。

claude mcp add design-dawn -- /path/to/design-dawn-mcp
