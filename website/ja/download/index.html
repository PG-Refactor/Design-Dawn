Design Dawn のダウンロードと始め方

Design Dawn は MIT ライセンスの無料・オープンソースのアプリです。ビルド済みのものは Windows 11（64ビット）用を配布しています。Linux ではソースからビルドします。macOS 版はありません。

GitHub の最新リリースへ

Windows 11

  1. 最新リリースのページで DesignDawn-<バージョン>-windows-x64.zip をダウンロードします。
  2. zip を好きな場所に展開します。中身はアプリ（design-dawn.exe）、MCP サーバー（design-dawn-mcp.exe）、ライセンス、サードパーティのライセンス表示です。
  3. design-dawn.exe を実行します。インストーラーはありません。

コード署名はしていません。Windows の SmartScreen が「Windows によって PC が保護されました」と表示することがあります。「詳細情報」→「実行」を選んでください。この操作は、このプロジェクトの GitHub のリリースページから入手したファイルか、自分でビルドしたファイルに対してだけ行ってください。

更新するときは、新しい zip を古いファイルに上書きで展開します。設定は引き継がれます。アプリは WebView2 ランタイムを使いますが、Windows 11 には最初から入っています。

Linux

ビルド済みの Linux 用パッケージはありません。Docker の開発コンテナの中でビルドでき、.deb パッケージも作れます。手順は README にあります。

任意：Git

アプリ内の Git 機能は PC の git コマンドを使い、Git 2.25 以上が必要です。Git が無くても、それ以外の機能はそのまま使えます。

最初の手順

  1. Project を作る。ファイル → 新規Project… を選び、フォルダを決めます。Project はディスク上の普通のフォルダです。
  2. Document を追加する。Project ツリーで Document を作成します。Document は1枚以上の Sheet からなり、Sheet は後から追加できます。
  3. ブロックを置く。+ Block で Markdown か Mermaid のブロックを追加します。画像（PNG・JPEG・WebP・SVG・GIF）は、シートへのドラッグ & ドロップかファイル選択で追加します。
  4. 編集する。ブロックをダブルクリックすると編集できます。Markdown はソースとプレビューの表示で開きます。Mermaid の図は、GUI で編集できる図なら GUI 編集で、そうでなければソースで開きます。
  5. 保存する。ファイル → 保存 を使うか、自動保存 をオンにします。

知っておくとよいこと

  • Markdown ブロックでは、HTML のタグは文字としてそのまま表示され、Markdown の画像記法は代替テキストだけが表示されます。画像を見せたいときは画像ブロックを使ってください。
  • Markdown ブロックのリンクは表示されますが、アプリがリンク先を開くことはありません。
  • 表示言語は日本語と英語、テーマはライトとダークを選べます。
