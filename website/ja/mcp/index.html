ローカルの MCP サーバーで、AI と設計書を書く

design-dawn-mcp は Design Dawn に付属する小さなプログラムです。MCP（Model Context Protocol）に対応しているので、Claude・Codex・GitHub Copilot・Cursor などの MCP クライアントが設計書を読み、あなたが許可したときだけ編集できます。

設定は AI ツールごとに1回

アプリで ファイル → AI連携（MCP） を開くと、登録するコマンドがコピーボタン付きで表示されます。同じ内容が、共通の JSON 形式でも表示されます。

{
  "mcpServers": {
    "design-dawn": { "command": "C:\\path\\to\\design-dawn-mcp.exe" }
  }
}

お使いの AI ツールの MCP サーバー追加の方法で登録してください。Claude Code の場合の例：

claude mcp add design-dawn -- <コマンド>

登録で Project を指定する必要はなく、サーバーに引数も要りません。サーバーは標準入出力だけで通信します。ネットワークポートは開かず、アプリが起動していなくても動きます。

AI に見せる Project は自分で選ぶ

AI ツールが使えるのは、AI 連携の画面の一覧にある Project だけです。一覧へは画面から追加するか（今開いているProjectを追加、または フォルダを指定して追加…）、AI に addProject で追加させます（その呼び出しは AI ツールであなたが承認します）。追加済みであれば、アプリで開いている Project が既定の対象になります。AI は追加済みの Project の一覧を取得して選べるので、「order-service の Project を要約して」のような依頼に、登録のやり直しは要りません。

許可するまでは読み取り専用

一覧の Project は、編集が許可されるまで AI からは読み取り専用です。横の AIによる編集を許可 にチェックを入れるか、AI に setWriteAccess を呼ばせて許可します。読み取り以外のツールの呼び出しと同じく、addProject・setWriteAccess・各変更は、AI ツールの中であなたが承認します（Claude Code の許可の確認など）。AI と作業している場所で判断できます。

一覧はアプリの設定フォルダに ai-access.json として保存され（Project の中には置きません）、アプリと MCP サーバーで共有します。AI が変えた内容はすぐ AI 連携の画面に反映され、AI による変更はすべて AIの変更履歴 に残ります。

AI ツールにできること

対象の Projectツール
一覧の Project すべてlistProjects, selectProject, addProject, setWriteAccess, getProject, getDocument, getSheet, getBlock, searchProject, exportMarkdown, listTemplates
編集が許可された ProjectcreateDocument, createSheet, createBlock, createFromTemplate, updateDocument, updateSheet, updateBlock, moveBlock, updateBlockDisplay, updateBlockCaption, deleteBlock, importImage
  • createBlock で作れるのは Markdown と Mermaid のブロックです。importImage は、このパソコンの画像ファイルを画像ブロックとして追加します。updateBlockDisplay はブロックの表示サイズ（またはブロックに合わせる自動調整）を、updateBlockCaption は Mermaid ブロックと画像ブロックのキャプションを設定します。
  • ブロックの本文を変えるとき、AI は getBlock で読んだ contentHash を一緒に送ります。その間に本文が変わっていれば、あなたの編集を上書きせず conflict を返します。
  • アプリがその Project を開いていれば、AI による変更はすぐ画面に反映されます。

できないこと

このサーバーは、Document・Sheet・Project の削除、コマンドの実行、Git の操作、ネットワーク接続を行えません。importImage（指定された画像を Project へコピーする）を除き、一覧の Project の外は読み書きしません。

Windows 版のダウンロードには、アプリと同じフォルダに design-dawn-mcp.exe が入っています。ダウンロードと始め方、AI が編集したファイルを Git で管理する方法もご覧ください。
