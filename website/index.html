Design documents on a free-form canvas

Design Dawn is a free, open-source desktop app for writing software design documents. Place Markdown, Mermaid diagrams and images anywhere on a sheet — and keep everything as plain files that people can read, Git can diff, and AI tools can safely edit.

Get it on GitHub Download for Windows Build from source

A Markdown and Mermaid editor built for design docs

A document is a set of sheets; each sheet holds freely placed blocks. Edit text, diagrams and screenshots side by side instead of in one long scroll.

Free-form canvas

Pan, zoom, select, move, resize, align and reorder blocks, with undo/redo for every edit.

Project tree

Documents in folders, several open at once; drag rows to reorder or move them.

Markdown blocks

Rendered on the canvas; split source/preview editor while you write.

Mermaid diagrams

Any Mermaid diagram, rendered locally and sanitised — no network, no scripts.

Mermaid GUI editor

Edit flowcharts, sequence diagrams, Gantt and pie charts with lists and property fields. The Mermaid source stays the single source of truth.

Git integration

Status, stage, commit, history, side-by-side diffs, fetch, pull and push without leaving the app.

External change detection

Edits from another editor, Git or an AI tool are picked up; reload, keep yours or compare.

Images and captions

PNG, JPEG, WebP, SVG and GIF by drag and drop, with one-line captions for figures.

Light / dark, English / Japanese

Both themes and both UI languages are built in.

Screenshots

Diagrams you can edit without memorising syntax, and diffs that stay readable.

Docs as code: plain files, readable diffs

Layout lives in small JSON files and content lives in .md and .mmd files. Review design changes in pull requests, and let a person or an AI change one block without touching the rest. Every JSON file carries a schemaVersion, and IDs are stable UUIDs.

No proprietary database and no lock-in: if you stop using Design Dawn, your documents are still Markdown and Mermaid.

Let AI read and edit your design docs (MCP)

design-dawn-mcp is a local MCP server (stdio only, no network port) that lets Claude, Codex, GitHub Copilot, Cursor and other MCP clients read and edit the projects you offer to them.

Every project is read-only for AI until you allow editing. An AI can ask for write access, but only your answer in the app counts. Edits use content hashes, so concurrent changes become conflicts instead of silent overwrites.

claude mcp add design-dawn -- /path/to/design-dawn-mcp

FAQ

Is Design Dawn free?

Yes. It is open source under the MIT License.

Which platforms are supported?

Windows 11, with a ready-to-run download. On Linux it can be built from source. It is built with Tauri 2 (Rust and TypeScript).

How is it different from a Markdown editor or a whiteboard tool?

It combines both: Markdown and Mermaid blocks are placed freely on sheets like a whiteboard, but everything is saved as plain text files that work with Git and code review.

Does it need an internet connection?

No. Diagrams are rendered locally, and the MCP server opens no network connections.
