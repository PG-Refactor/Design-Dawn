Download Design Dawn and take the first steps

Design Dawn is free and open source under the MIT License. A ready-made build is available for Windows 11 (64-bit). On Linux it is built from source. There is no macOS build.

Go to the latest release on GitHub

Windows 11

  1. On the latest release page, download DesignDawn-<version>-windows-x64.zip.
  2. Extract the zip anywhere. It contains the app (design-dawn.exe), the MCP server (design-dawn-mcp.exe), the license and the third-party notices.
  3. Run design-dawn.exe. There is no installer.

The build is not code-signed. Windows SmartScreen may show “Windows protected your PC”. Choose “More info”, then “Run anyway”. Only do this for a file you downloaded from the project’s GitHub releases page or built yourself.

To update, extract a newer zip over the old files; your settings are kept. The app uses the WebView2 runtime, which Windows 11 includes.

Linux

There is no ready-made Linux package. The project builds inside a Docker dev container, and can produce a .deb package; the steps are in the README.

Optional: Git

The built-in Git features use the git command on your computer and need Git 2.25 or later. Without Git, the rest of the app works as usual.

First steps

  1. Create a project. Choose File → New Project… and pick a folder. A project is an ordinary folder on your disk.
  2. Add a document. Use New Document in the project tree. A document has one or more sheets; add more with New Sheet.
  3. Place blocks. + Block adds a Markdown or Mermaid block. Images (PNG, JPEG, WebP, SVG, GIF) are added by dropping files onto the sheet or from a file dialog.
  4. Edit. Double-click a block to edit it. Markdown opens as source with a preview; a Mermaid diagram opens in the GUI editor when the GUI can edit it, otherwise as source.
  5. Save. Use File → Save, or turn on Auto Save.

Good to know

  • In a Markdown block, raw HTML is shown as text, and Markdown image syntax shows only its alt text. To show a picture, use an image block.
  • Links in a Markdown block are displayed but are not opened by the app.
  • The UI is available in English and Japanese, with light and dark themes.
