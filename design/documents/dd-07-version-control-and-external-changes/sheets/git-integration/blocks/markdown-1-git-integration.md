# Git Integration

- The project folder is treated as a Git repository
- Uses the `git` command installed on the computer

## Operations
- Status, stage, unstage, commit (amend, commit and push), history
- Side-by-side text diff and visual before/after of a sheet
- Fetch, pull, push; undo of the last commit
- Merge conflict resolution: text side by side, `sheet.json` block by block, images by comparing both versions

## Not Provided
- Force push, history rewriting
