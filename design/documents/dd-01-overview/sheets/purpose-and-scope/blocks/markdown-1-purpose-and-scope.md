# Purpose and Scope

## Purpose
- Design documents that people and AI tools can both read and change
- Documents readable and editable as plain files, without the application
- Reviewable changes through Git diffs and pull requests
- Partial, safe changes by AI, one block at a time

## In Scope
- Desktop application for writing design documents on a free-form canvas
- Local MCP server for AI tools
- Git operations on the project folder

## Out of Scope
- Hosted service, accounts, real-time co-editing
- Relationships between blocks (expressed in diagrams or text instead)
