# Glossary

| Term | Definition |
|---|---|
| Project | A set of design documents: one folder holding `project.json` |
| Folder | A container of Documents and Folders inside a Project |
| Document | One design document; an ordered list of Sheets |
| Sheet | One free-form canvas holding Blocks |
| Block | An element on a Sheet: Markdown, Mermaid or Image |
| Entry point (`.dawn`) | A small file that opens a Document from a file manager; not the Document itself |
| Application Command | One user operation as a unit of undo / redo |
| Content hash | Hash of a file's content, used to detect changes made elsewhere |
| MCP | Model Context Protocol; the interface AI tools use to call the server |
