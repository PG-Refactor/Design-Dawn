# Why This Layout

| Change | Files in the diff |
|---|---|
| Edit text | One `.md` file |
| Edit a diagram | One `.mmd` file |
| Move or resize a block | Numbers in one `sheet.json` |
| Rename a document | `name` in one `document.json` |
| Add an image | One file in `assets/` and one `sheet.json` |

- Content readable as Markdown and Mermaid without the application
- One block replaceable by an AI tool without touching the rest
