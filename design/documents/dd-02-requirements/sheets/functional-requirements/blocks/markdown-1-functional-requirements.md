# Functional Requirements

| ID | Requirement |
|---|---|
| FR-01 | Hierarchy of Project, Folder, Document, Sheet and Block |
| FR-02 | Free placement of Markdown, Mermaid and Image blocks; pan, zoom, move, resize, align, z-order, copy and paste |
| FR-03 | Markdown editing with split source and preview |
| FR-04 | Mermaid rendering; GUI editing of flowchart, sequence, class, state, ER, Gantt and pie diagrams |
| FR-05 | Undo and redo of edits as Application Commands |
| FR-06 | Auto save, with manual save (Ctrl+S) when auto save is off |
| FR-07 | Detection of changes made outside the application, with reload, keep or compare |
| FR-08 | Git status, stage, commit, history, diff, fetch, pull, push and merge conflict resolution |
| FR-09 | Read and write access for AI tools through a local MCP server, per project |
| FR-10 | Templates, project-wide search, printing, export to PDF, HTML and Markdown |
