# Constraints and Assumptions

## Constraints
- Single-user desktop application; collaboration through Git
- Git features use the `git` command installed on the computer
- Block types limited to Markdown, Mermaid and Image
- No relationship model between blocks (DEC-04 in DD-03)

## Assumptions
- Project folders kept under Git by the user
- AI tools support MCP over standard input and output
- The user approves AI tool calls that change data, in the AI tool
