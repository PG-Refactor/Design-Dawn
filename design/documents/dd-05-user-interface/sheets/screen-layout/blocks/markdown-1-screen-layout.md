# Screen Layout

| Area | Content |
|---|---|
| Top | Menu bar (File, View, Help); short notices |
| Left | Sidebar: Project tree, search, Git; can be folded |
| Right, top | Document tabs |
| Right, centre | Canvas of the active sheet |
| Right, bottom | Sheet tabs |

- Several documents open at once; a document can move to its own window
- Themes: System, Light, Dark. Languages: English, Japanese
